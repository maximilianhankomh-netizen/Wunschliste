Anmelden

Zum Bearbeiten brauchst du einmalig einen Admin-Schlüssel von GitHub. Er erlaubt nur, die Dateien dieser Wunschliste zu ändern.

  1. Schlüssel bei GitHub erstellen ↗ (du musst bei GitHub angemeldet sein). Name, Ablauf nach einem Jahr und die Berechtigung Contents: Read and write sind schon vorausgefüllt.
  2. Bei Repository access „Only select repositories“ wählen und Wunschliste auswählen. Das musst du selbst machen.
  3. Ganz unten auf Generate token klicken, den Schlüssel kopieren und hier einfügen.

Der Schlüssel wird nur in diesem Browser gespeichert und nur an GitHub gesendet. Auf fremden Geräten den Haken weglassen.
